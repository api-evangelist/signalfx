# SignalFx (Splunk Observability Cloud)

> SignalFx is a cloud monitoring and observability platform for modern infrastructure and microservices (founded 2013, acquired by Splunk in 2019, now delivered as Splunk Observability Cloud). It ingests high-resolution time-series metrics, events, and traces and applies real-time streaming analytics (SignalFlow) to power dashboards, detectors, and alerts. APIs are realm-based and authenticated with an X-SF-Token header.

## APIs

- [SignalFx REST API](https://dev.splunk.com/observability/reference): Metadata and configuration — detectors, charts, dashboards, teams, data links, SLOs, tokens, metric rulesets, and cloud/notification integrations. Base host api.{realm}.signalfx.com.
- [Data Ingest API](https://dev.splunk.com/observability/docs/datamodel/ingest/): Send datapoints (gauges, counters, cumulative counters) and events. Host ingest.{realm}.signalfx.com.
- [SignalFlow API](https://dev.splunk.com/observability/docs/signalflow/messages/): Real-time streaming analytics computations. Host stream.{realm}.signalfx.com.

## Authentication

- [Auth profile](authentication/signalfx-authentication.yml): X-SF-Token header. Org/ingest token (ingest), API/session token (REST), access token (SignalFlow).

## Conventions

- [API conventions](conventions/signalfx-conventions.yml): Realm-based hosts, limit/offset pagination (count/results), JSON bodies, HTTP 429 rate limiting.

## SDKs

- [Packages](packages/signalfx-packages.yml): Go (signalfx-go, active), Python, Node.js, Java, Ruby (deprecated toward OpenTelemetry).
